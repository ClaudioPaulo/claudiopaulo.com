# claudiopaulo.com

Personal portfolio of Cláudio Paulo, backend software engineer based in Lisbon.

A static, responsive site built with plain HTML, CSS and a little JavaScript. No build step and no dependencies apart from Google Fonts.

## Languages

The site is available in English (`/`) and European Portuguese (`/pt/`). Each language is a separate static page, which is better for search engines and for link previews than switching text with JavaScript, and it works without JavaScript.

- `index.html` is the **English source of truth**. `pt/index.html` is generated from it.
- `i18n/pt.json` maps the exact English text of each element to its Portuguese translation (plus translated attributes, meta tags and a few page-specific replacements).
- `build_i18n.py` generates `pt/index.html`. After editing `index.html`, run `python3 build_i18n.py --check`. It fails if some text was left untranslated or if a dictionary entry no longer matches the English page. Commit the generated page together with your change.
- The **Resume** button opens the CV in the language of the page: `resume/Claudio-Paulo-CV.pdf` (English) or `resume/CV-Claudio-Paulo.pdf` (Portuguese). Ctrl/Cmd+P also prints in the page's language.
- Each page has `hreflang` alternates, its own canonical URL and Open Graph locale, and `sitemap.xml` lists both versions.

To add a language (for example French): create `i18n/fr.json` (copy `pt.json` and translate the values), add `'fr'` to `LANGS` in `build_i18n.py`, add a `FR` link to the language switcher in `index.html`, add the `hreflang` link and sitemap entry, and add a CV in that language under `resume/`. Only add a language you can support in an interview.

## Profile photo

The portrait is `assets/profile.jpg` (4:5, about 640x800 px, under 100 KB, no metadata). It appears in the About section as a green duotone that fades to the original photo on hover (or on tap). The duotone is an SVG filter defined at the top of `index.html`; change its `tableValues` to retune the color. If the file is missing, a "CP" monogram is shown instead. Remove location and other metadata from any photo before publishing (for example `exiftool -all= photo.jpg`).

## Features

- Dark navy and teal theme defined as CSS variables in `css/styles.css`.
- Experience section with keyboard-accessible tabs (arrow keys, Home, End).
- Respects `prefers-reduced-motion`.

- Impact strip, a stack line per employer, and "How it works" case studies with architecture diagrams (inline SVG, no images) for the two projects.
- SEO and sharing: Open Graph and Twitter cards, JSON-LD `Person` data, canonical URL, `robots.txt` and `sitemap.xml`.

## Colors and typography

- Palette: graphite with a green accent (`#0d1117` background, `#3fb950` accent, `#58a6ff` links). Every color is a CSS variable on `:root` in `css/styles.css`, so changing the look means editing that one block.
- Fonts: IBM Plex Sans and JetBrains Mono, self-hosted in `assets/fonts/` (SIL Open Font License, licenses included). The page makes no third-party requests.

## Security and hosting files

- A strict Content-Security-Policy is set in a `<meta>` tag in `index.html`, so it also applies on GitHub Pages. If you add an external script, image host or analytics, update that policy.
- `_headers` sets the same policy plus other security headers on Netlify and Cloudflare Pages (GitHub Pages ignores it).
- `.well-known/security.txt` gives security researchers a contact (RFC 9116). Its `Expires` date is **2027-10-10**: renew it before then.
- `.nojekyll` stops GitHub Pages from ignoring the `.well-known` folder.

## Updating the CV

Edit `resume/cv_claudio_paulo.html`, open it in Chrome, print to PDF (A4, background graphics on) and save it over `resume/Claudio-Paulo-CV.pdf`. Also update `resume/resume.json` so both stay in sync. Role-specific variants (for example Java backend or Cloud and DevOps) are for direct applications and are kept outside this repository. The public CV leaves out the phone number on purpose.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deploy

It is a static site, so it can be hosted on GitHub Pages, Netlify, Vercel or Cloudflare Pages. For GitHub Pages with the custom domain, keep the `CNAME` file and point the domain's DNS to GitHub Pages. On other hosts the `CNAME` file is ignored and can be deleted.
